# F-06 图层控制面板实施计划

## Summary

- 在现有 `/mgmt/gis` 上升级 F-05 图层插槽为正式图层控制面板：显隐、透明度、图例、状态持久化。
- 沿用 F-01~F-05 暗色数据密集 dashboard 风格：玻璃面板、蓝色数据态、琥珀选中态、红色告警态与紧凑运维布局。
- 图层切换不重建 Leaflet map、不重新请求 bbox；每个业务图层维护独立 `LayerGroup`，显隐只 add/remove group，透明度只更新 style。
- 接入后端现有接口，不新增后端 API：GIS bbox/detail/pick + `GET /api/alerts`。
- 完成后提交并推送到 `origin/feature/F-01-F-03-frontend-portal-auth`。

## Key Changes

- 图层状态：新增图层配置、图例、持久化状态与告警响应类型，图层固定为 `SEGMENT / DEVICE / NODE / FACILITY / ALERT`。
- 控制面板：支持单层显隐、单层透明度、图例折叠、全部显示、全部隐藏、恢复默认。
- 状态持久化：使用 `localStorage` key `uscdip.gis.layerState.v1` 保存显隐、透明度和图例折叠状态。
- Leaflet 重构：bbox 加载后创建对象 layer；后续切图层只操作 `LayerGroup`，调整透明度只调用 `setStyle`。
- 告警图层：调用 `GET /api/alerts?page=1&pageSize=50`，按 `deviceId / segmentId / nodeId` 匹配当前 bbox GIS 对象，能定位则绘制告警标记，不能定位则只计数。

## Public APIs / Interfaces

- 后端接口不变：
  - `GET /api/gis/objects/bbox`
  - `POST /api/gis/objects/pick`
  - `GET /api/gis/objects/{objectType}/{objectId}`
  - `GET /api/alerts?page=1&pageSize=50`
- 前端新增：
  - `getAlerts()` service。
  - `ALERT` 虚拟图层，不进入 GIS bbox objectType 参数。
  - `MapLayerConfig / MapLayerState / MapLayerLegendItem / LayerPersistencePayload / AlertRecordResponse` 类型。

## Test Plan

- 静态检查：`cd frontend && npm run typecheck`、`cd frontend && npm run build`。
- 切换管线/设备/节点/设施/告警显隐，地图不重新初始化，不重新请求 bbox。
- 调整透明度，已绘制对象即时更新；选中对象保持高亮。
- 刷新页面后，图层显隐、透明度、图例折叠状态恢复。
- “恢复默认”清理持久化并恢复默认层状态。
- `/api/alerts` 成功时，可匹配对象的告警叠加到地图；401/403/5xx 时只影响告警图层状态，不影响 GIS 基础图层。

## Assumptions

- F-06 不新增后端 API，也不保存用户偏好到数据库；图层偏好使用 `localStorage`。
- 告警图层只叠加当前 bbox 已加载对象能定位的告警；跨 bbox 告警留给 F-07/F-11 后续联动。
- F-06 不实现资产搜索、详情业务扩展、WebSocket 实时刷新；这些分别留给 F-07/F-08/F-11。
- `backend/src/main/resources/data.sql` 是既有无关脏改动，不纳入本次提交。

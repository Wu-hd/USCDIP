# F-07 资产对象检索与地图定位实施计划

## Summary

- 在现有 `/mgmt/gis` 页面新增资产对象检索与地图定位能力，支持按对象编码、名称、类型检索 `NODE / SEGMENT / FACILITY / DEVICE`。
- 视觉沿用 F-05/F-06 的深色 SaaS analytics dashboard 风格：紧凑面板、蓝色数据态、琥珀定位态、Lucide 图标与可访问焦点态。
- 不新增后端接口；前端通过主数据分页接口建立检索索引，选中结果后调用 GIS 单对象详情接口定位并打开现有详情抽屉。
- 非当前 bbox 对象使用独立搜索高亮层展示，不污染 bbox 对象统计。

## Key Changes

- GIS 页面：左侧面板顶部新增“资产检索”，包含关键词输入、对象类型筛选、搜索状态、结果列表、清空与刷新索引。
- 检索数据流：新增 `masterData` 前端 service，分页读取 `/api/master/nodes|segments|facilities|devices`；前端按 `objectId / objectName / objectType` 匹配。
- 地图定位：点击搜索结果后调用 `GET /api/gis/objects/{objectType}/{objectId}?displaySrid=EPSG:4490`，定位 `POINT / LINESTRING`，自动打开右侧详情抽屉。
- 图层联动：定位前确保对应业务图层可见；bbox 外对象使用独立琥珀色高亮图层，bbox 内对象复用既有选中高亮。
- 错误反馈：主数据索引、GIS 详情 401/403/404/5xx 均在搜索状态区显示错误与 traceId，不伪造空间坐标。

## Public APIs / Interfaces

- 后端接口不变，前端联调使用：
  - `GET /api/master/nodes?page=1&pageSize=100`
  - `GET /api/master/segments?page=1&pageSize=100`
  - `GET /api/master/facilities?page=1&pageSize=100`
  - `GET /api/master/devices?page=1&pageSize=100`
  - `GET /api/gis/objects/{objectType}/{objectId}?displaySrid=EPSG:4490`
- 新增前端类型：`MasterDataRecordResponse`、`AssetSearchType`、`AssetSearchResult`、`AssetSearchIndexState`。
- 搜索默认值：关键词最少 2 个字符触发，防抖 250ms，分页 `pageSize=100`，每类型最多加载 10 页。

## Test Plan

- 静态检查：`cd frontend && npm run typecheck`、`cd frontend && npm run build`。
- 检索验证：搜索 `NODE-001`、`SEG-001`、`压力传感器`，结果展示对象类型、名称、编码、regionId、status。
- 类型筛选：切换 `全部 / 节点 / 管线 / 设施 / 设备`，结果范围随筛选变化，空结果显示建议关键词。
- 地图定位：点击结果后地图移动到对象，目标对象高亮，详情抽屉自动打开；隐藏对应图层后定位会自动恢复可见。
- 错误场景：主数据接口失败、GIS 详情 401/403/404/5xx 时页面不崩溃，显示错误和 traceId。

## Assumptions

- F-07 不新增后端搜索接口；后续资产量变大时再落地统一后端搜索。
- F-07 只负责资产检索、地图定位、打开现有详情抽屉；详情抽屉业务标签页留给 F-08。
- `backend/src/main/resources/data.sql` 是既有无关脏改动，不纳入本次提交。

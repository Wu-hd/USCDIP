# F-09 设备台账列表页实施计划

## Summary

- 新增 `/mgmt/devices` 设备台账列表页，作为综合管理平台的设备运行态入口。
- 页面展示 `deviceId`、协议类型、在线状态、最近心跳、缓冲水位、标定有效期和对象链字段。
- 视觉沿用 F-05~F-08 深色 SaaS analytics dashboard 风格：紧凑指标卡、玻璃面板、蓝色数据态、琥珀预警态、红色离线/过期态与 Lucide 图标。
- 不新增后端接口；前端复用设备台账分页和详情接口，并直接展示后端计算的 `onlineStatus` 与 `onlineStatusReason`。

## Key Changes

- 路由入口：新增 `/mgmt/devices`，权限沿用 `ENTRY:MGMT + MENU:ASSET:READ`；在 `/mgmt` 平台入口页增加“设备台账”入口。
- 列表页面：顶部展示当前页聚合指标，包括设备数、在线、预警、离线、标定过期和缓冲水位概览。
- 筛选与分页：支持状态、协议、regionId、segmentId、nodeId、facilityId、calibrationExpired 和 pageSize；分页使用后端 `page/pageSize`。
- 状态展示：在线状态以 `onlineStatus + onlineStatusReason` 为准，结合最近心跳、接收时间、缓冲水位和异常标记展示，不在前端重新简化为布尔状态。
- 行详情：点击设备行打开右侧详情面板，展示心跳链路、缓冲异常、对象链、标定到期和版本号，并支持刷新当前设备详情。
- 响应式：桌面使用高密度表格，移动端降级为设备卡片列表。

## Public APIs / Interfaces

- 使用现有后端接口：
  - `GET /api/device-ledger/devices?page=1&pageSize=20&status=&regionId=&segmentId=&nodeId=&facilityId=&protocolType=&calibrationExpired=`
  - `GET /api/device-ledger/devices/{deviceId}`
- 复用前端类型与 service：
  - `DeviceLedgerResponse`
  - `DeviceLedgerQuery`
  - `getDeviceLedgerDevices()`
  - `getDeviceLedgerDevice()`
- 后端接口不改；错误态复用统一 `ApiClientError` 与 traceId 展示。

## Test Plan

- 静态检查：`cd frontend && npm run typecheck`、`cd frontend && npm run build`。
- 页面验证：访问 `/mgmt/devices`，确认列表加载并展示 `DEV-001 / DEV-002 / DEV-003`。
- 状态验证：`DEV-001` 在线正常，`DEV-002` 高缓冲预警且标定过期，`DEV-003` 心跳超时离线。
- 筛选验证：分别切换状态、协议、标定过期、region/segment/node/facility 条件，确认请求参数正确、列表结果刷新、分页重置到第一页。
- 详情验证：点击设备行打开详情面板；刷新当前设备时调用 `/api/device-ledger/devices/{deviceId}` 并更新详情。
- 错误验证：列表或详情接口 401/403/404/5xx 时页面不崩溃，并展示错误和 traceId。

## Assumptions

- F-09 只实现设备台账只读列表和单设备详情预览，不实现注册、编辑、心跳上报或批量操作。
- 页面统计为当前查询页数据的前端聚合，后续如需全量统计再新增后端聚合接口。
- `backend/src/main/resources/data.sql` 是既有未提交改动，不纳入本次提交。

# F-10 时序趋势图页实施计划

## Summary

- 新增 `/mgmt/trends` 时序趋势图页，作为综合管理平台的设备指标趋势入口。
- 页面支持按设备、指标、时间范围、DQ 等级、在线/补偿数据查询，并展示指标值与 DQ 分数趋势。
- 视觉沿用 F-05~F-09 深色 SaaS analytics dashboard 风格：玻璃面板、蓝色趋势线、琥珀补偿点、红色低质量点和 Lucide 图标。
- 扩展 `GET /api/dq/scores` 增加 `startTime/endTime`，按 `ts_metric.event_time` 做后端时间过滤。

## Key Changes

- 后端接口：`/api/dq/scores` 新增 `startTime/endTime` 查询参数，使用 ISO DateTime；`startTime > endTime` 返回 `DQ_QUERY_INVALID`。
- 前端服务：新增 `dataQuality.ts`，封装 DQ 分页查询与单条详情查询。
- 前端类型：新增 `DataQualityScoreResponse`、`TrendMetricPoint`，复用 `PageResponse` 和统一 `ApiClientError`。
- 页面入口：新增 `/mgmt/trends` 路由，权限为 `ENTRY:MGMT + MENU:ASSET:READ`；`/mgmt` 增加“时序趋势”入口；设备台账详情增加“查看趋势”跳转。
- 图表交互：使用 Vue + SVG 自绘折线图，不新增图表依赖；在线样本使用蓝色点，补偿样本使用琥珀菱形，低质量点使用红色强调。
- 明细展示：下方表格展示 `sourceRecordId / eventTime / metricValue / isBackfill / dqScore / dqLevel / dqFlags / recvTime / deviceTime`。

## Public APIs / Interfaces

- 扩展现有接口：
  - `GET /api/dq/scores?page=1&pageSize=100&deviceId=&metricCode=&dqLevel=&minScore=&maxScore=&sourceBatchId=&isBackfill=&startTime=&endTime=`
  - `GET /api/dq/scores/{sourceRecordId}`
- 默认页面查询：
  - `deviceId=DEV-001`
  - `metricCode=PRESSURE`
  - 最近 7 天
  - `pageSize=100`
- 图表只绘制当前页结果；当后端 `total > pageSize` 时显示分页截断提示。

## Test Plan

- 后端：`cd backend && mvn test -Dtest=DataQualityIntegrationTest`。
- 前端：`cd frontend && npm run typecheck`、`cd frontend && npm run build`。
- 页面验证：访问 `/mgmt/trends?deviceId=DEV-001&metricCode=PRESSURE`，确认趋势图、DQ 概览和明细表加载。
- 时间筛选：切换最近 24 小时、7 天、自定义时间，Network 请求应携带 `startTime/endTime`。
- 补偿区分：筛选 `isBackfill=true` 时，补偿点必须以琥珀样式区别于在线数据。
- 质量标识：查询 `dqLevel=D` 时，低质量点在图中以红色强调，`dqFlags` 在点位详情和明细表可见。

## Assumptions

- F-10 属于综合管理平台运行态趋势页，不使用 DIAG 的脱敏特征视图接口。
- F-10 只做只读趋势查询，不实现实时 WebSocket 刷新。
- `backend/src/main/resources/data.sql` 是既有未提交改动，不纳入本次提交。

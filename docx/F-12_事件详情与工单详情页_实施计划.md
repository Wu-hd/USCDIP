# F-12 事件详情与工单详情页 - 实施计划

## 1. 目标
完成地下管网健康监测系统的主业务链路的末端展示页：
- **事件详情页**：展示告警升级后的综合分析与确认状态。
- **工单详情页**：展示派发后的物理设备检修、维护的时间线记录。

## 2. 设计规范
与现有 F-11 保持同样的 SaaS Analytics Dashboard UI/UX 规范：
- 亮暗色支持 (`bg-slate-50 dark:bg-ink`)
- 状态胶囊标签体系（待确认、处理中、已恢复等）
- 右侧聚合处置时间线（Timeline）

## 3. 实现内容
- 前端路由 (`/mgmt/incidents/:id`, `/emgc/workorders/:id`)
- `IncidentDetailView.vue` 和 `WorkOrderDetailView.vue` 组件
- `incidents.ts` 和 `workorders.ts` API 方法补全

## 4. 后续任务接口预留
保留 `handleConfirm`、`handleAccept` 动作插槽，数据与时间线将从后端主数据和流转记录动态渲染。

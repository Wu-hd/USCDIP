# F-15 3D 占位与降级页 - 实施计划

## 1. 目标
新增 `/mgmt/gis/3d` 3D 占位页，为二期数字孪生和动态推演预留稳定入口；一期不新增后端 3D API，复用现有 B-10 GIS 数据生成轻量线框，并确保 3D 不可用时自动回到 2D 主入口。

## 2. 设计规范
- 使用 `ui-ux-pro-max` 的 SaaS Analytics Dashboard 风格：深色运维底图、蓝色空间数据层、琥珀色降级提示、高密度状态卡片。
- 3D 场景全屏展示，不放在装饰卡片内；右侧保留联调状态、bbox、对象上下文、降级规则。
- loading、fallback、traceId、手动返回与暂停倒计时必须可见。

## 3. 前后端联调契约
- 不新增后端接口。
- 复用 `GET /api/gis/objects/bbox` 加载占位线框对象。
- 复用 `GET /api/gis/objects/{objectType}/{objectId}` 恢复选中对象上下文。
- 权限沿用 `/mgmt/gis`：`ENTRY:MGMT + MENU:ASSET:READ`。

## 4. 实现内容
- 新增 Three.js 依赖：`three / @types/three`。
- 新增路由 `/mgmt/gis/3d` 与页面 `Gis3DPlaceholderView.vue`。
- 在 `/mgmt/gis` 和 `/mgmt` 平台入口增加“3D 占位”入口。
- 2D 入口携带 `objectType / objectId / displaySrid / minX / minY / maxX / maxY` query。
- 3D 页面按 bbox 绘制管线、节点、设备、设施的轻量线框；若 query 中有对象，则优先高亮该对象。
- 2D 页面读取从 3D 回退带回的 query，恢复 bbox 并定位对象详情。

## 5. 降级规则
- WebGL 不可用、Three 初始化异常或 canvas 容器不可用：立即进入 fallback 状态。
- GIS bbox/detail 返回 401/403/404/5xx 或空数据：展示原因和 traceId，3 秒后回退 2D。
- 回退目标固定为 `/mgmt/gis`，并保留原始 query；用户可手动立即返回或暂停倒计时。

## 6. 验收与测试
- `npm run typecheck`
- `npm run build`
- 启动 Vite 后检查 `/mgmt/gis/3d` 桌面与移动视口，确认 canvas 非空、线框可见、UI 不重叠。
- 从 2D 未选对象进入 3D，应加载默认 bbox 线框。
- 选中 `NODE-001` 或 `SEG-001` 后进入 3D，再回到 2D，应保留对象上下文。
- 模拟 WebGL/API 失败时，应展示 fallback 原因并自动回 2D。

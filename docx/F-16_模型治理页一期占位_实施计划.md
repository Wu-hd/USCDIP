# F-16 模型治理页一期占位实施计划

## 目标
- 在智能诊断中枢新增 `/diag/models`，作为一期模型治理框架页。
- 页面真实联调 B-25 模型网关的模型列表、模型详情与模型回退接口。
- 一期不开放注册、创建版本、灰度调整、激活、推理与 B-26 明细复核写操作，只保留清晰入口和边界说明。

## 设计规范
- 参考 `ui-ux-pro-max` 数据密集型 SaaS Dashboard：深色运维背景、蓝色数据层级、琥珀色风险动作。
- 使用紧凑 KPI、注册表、版本表、状态徽标、回退弹窗和复核预留抽屉组织信息。
- 所有可点击控件必须有 hover/focus 状态；表格在移动端横向滚动，避免文字重叠。

## 联调接口
- `GET /api/models?page={page}&pageSize={pageSize}&status={status}`：读取模型注册表。
- `GET /api/models/{modelCode}`：读取模型详情和版本列表。
- `POST /api/models/{modelCode}/rollback`：提交回退。

回退请求体：

```json
{
  "targetVersionNo": "V1",
  "reason": "灰度异常，回退至上一稳定版本"
}
```

权限：
- 读取：`ENTRY:DIAG + MENU:MODEL:READ`
- 回退：`ENTRY:DIAG + MENU:MODEL:WRITE`

## UI 状态
- 注册表：loading、empty、error、ready、分页、状态过滤。
- 详情区：模型摘要、ACTIVE/GRAY 版本、版本列表、兜底开关、artifact 与 schema。
- 回退弹窗：目标版本选择、原因必填、提交中、成功、后端错误、traceId。
- 复核预留：说明二期承接 B-26 特征视图，不产生复核任务或越权明细访问。

## 验收点
- 算法工程师可读列表与详情，但回退按钮禁用并提示缺少 `MENU:MODEL:WRITE`。
- 管理员可执行回退，提交后刷新列表和详情，目标版本变为 `ACTIVE`。
- 401/403/404/5xx 均展示后端错误和 traceId。
- `npm run typecheck` 与 `npm run build` 通过。

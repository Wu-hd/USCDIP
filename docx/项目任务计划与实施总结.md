## 四、A 系列任务详细总结（前置冻结）

### A-01 统一菜单与平台边界表

- **目标：** 冻结 Portal、三平台、支撑层的菜单归属与路由前缀
- **实施工具：** Copilot（初始生成）→ Codex（数据库落地）
- **产出物：**
  - `a01-menu-boundary.json`：定义 PORTAL / MGMT / EMGC / DIAG / SUPPORT 五平台
  - 菜单归属冻结规则（单平台挂载、权限码规范、写操作约束）
  - 配置查询 API：`GET /api/menu-boundaries`、`GET /api/platforms`

### A-02 统一对象主键与对象链字典

- **目标：** 定义 node_id、segment_id、device_id 等主键规范
- **产出物：**
  - 7 类实体：`NodeEntity`、`SegmentEntity`、`FacilityEntity`、`DeviceEntity`、`IncidentEntity`、`WorkOrderEntity`、`ModelResultEntity`
  - `ObjectChainService` / `ObjectChainController`：按 segment_id / node_id 查询对象链
  - 对象字典查询与分页 API

### A-03 坐标与深度字段冻结

- **目标：** 统一 authority_srid、display_srid、geometry_2d、z_top、z_bottom、bury_depth
- **产出物：**
  - `NodeEntity` 包含完整 7 个坐标字段
  - `GisCoordinateService`：统一后端坐标转换（EPSG:4490↔3857），**禁止前端私算**
  - 深度一致性校验接口：`POST /api/gis/depth/validate`

### A-04 权限模型与数据范围矩阵

- **目标：** 建立角色、入口权限、数据范围、订阅范围矩阵
- **产出物：**
  - `a04-authz-matrix.json`：覆盖 5 种角色
  - `AuthorizationService` / `AuthzGuardAspect`：运行时约束
  - 约束表达式：`access = entryPermission && menuPermission && dataScope && topicScope`

### A-05 实时链路指标口径表

- **目标：** 统一 trace_id、event_time、recv_time、is_backfill、last_ack_seq
- **产出物：**
  - `TsMetricEntity` 区分 event_time / recv_time / device_time / trace_id / is_backfill
  - `TraceIdContext` + `TraceIdFilter` 贯穿 HTTP 链路
  - `WebSocketAckEntity` 包含 last_ack_seq
  - 查询 API：`GET /api/realtime-link/spec`

### A-06 事件状态机与工单状态机

- **目标：** 冻结告警、事件、工单三套状态枚举与流转规则
- **产出物：**
  - 告警：`AlertRecordEntity`（decision / processStatus / suppressed / escalationLevel）
  - 事件：`IncidentEntity`（status / confirmedBy / confirmedAt / resolvedAt / closeReason）
  - 工单：`WorkOrderStatus` 枚举（CREATED→DISPATCHED→ACCEPTED→COMPLETED→CLOSED）

### A-07 API 错误码与异常响应规范

- **目标：** 统一 success/data/error/traceId 结构与常用错误码
- **产出物：**
  - `ApiResponse<T>`：统一响应结构
  - `ErrorCode` 枚举：覆盖 79 种错误码
  - `GlobalExceptionHandler`：统一异常响应

## 五、B 系列任务详细总结（一期后端）

### B-01 统一 API 契约骨架

- **产出物：** `ApiResponse` / `PageResponse` / `ErrorCode` + OpenAPI 注解 + Swagger UI
- **技术栈：** Spring Boot 3.x + springdoc-openapi

### B-02 OIDC 登录集成

- **产出物：** `OidcAuthorizationService` / `OidcUserSyncService`
- **能力：** OIDC + PKCE + 用户信息同步 + 统一登出；支持默认本地模式（OIDC 可关闭）

### B-03 Access/Refresh Token 刷新轮换

- **产出物：** `LocalTokenService` / `LocalAccessTokenService`
- **能力：** AT=1800s / RT=1209600s；Rotation + 重放检测 + 安全审计

### B-04 Token 吊销与权限收敛

- **产出物：** `TokenRevocationService`
- **能力：** 3 种吊销路径（登出 / 禁用 / 权限变更）；`token_valid_after` 全平台收敛

### B-05 应急旁路账号与审计

- **产出物：** `EmergencyAccessService` / `EmergencyAuthController`
- **能力：** 旁路 AT=600s / RT=1800s；`BREAK_GLASS_COMMAND` 角色最小权限；独立审计

### B-06 Gateway 校验与限流

- **产出物：** `GatewayControlFilter` / `GatewayPolicyService` / `GatewayRateLimitService`
- **能力：** 路由策略、黑白名单、限流、高风险审计（单实例内存限流）

### B-07 RBAC + 数据范围 + 订阅范围

- **产出物：** `AuthorizationService` / `AuthzGuardAspect` / `TopicAuthorizationService` / `ObjectScopeService`
- **能力：** 声明式 `@AuthzGuard` 注解 + 联合鉴权 + topic 授权

### B-08 主数据表与对象链服务

- **产出物：** `MasterDataQueryService` / `MasterDataController` / `ObjectChainService` / `ObjectRelationEntity`
- **能力：** node / segment / facility / device 只读 API + 对象链遍历

### B-09 主数据版本与并发控制

- **产出物：** `MasterDataChangeService` / `MasterChangeRequestEntity` / `ObjectVersionEntity`
- **能力：** JPA `@Version` 乐观锁 + 变更申请审批 + 版本快照归档

### B-10 GIS 空间查询与坐标转换服务

- **产出物：** `GisSpatialQueryService` / `ObjectGeoIndexService` / `GisController`
- **能力：** bbox 查询、对象点查、空间索引 + JTS 坐标转换

### B-11 设备台账与心跳接口

- **产出物：** `DeviceLedgerService` / `DeviceLedgerController`
- **能力：** 设备注册 Upsert、心跳上报、ONLINE / WARNING / OFFLINE 三态计算

### B-12 统一入站 DTO 与协议适配骨架

- **产出物：** `UnifiedIngestService` / `ProtocolAdapterRegistry`
- **能力：** MQTT / MODBUS / NB_IOT 三种协议适配；区分 eventTime / recvTime / deviceTime

### B-13 TSDB 写入与补偿写入服务

- **产出物：** `TsdbWriteService` / `TsWriteLogEntity` / `TsdbWriteRetryScheduler`
- **能力：** 在线/补偿写入、is_backfill 标记、失败重试

### B-14 数据质量评分服务

- **产出物：** `DataQualityScoringService` / `DataQualityController`
- **能力：** dq_score 五维加权公式 `100 × (0.30C + 0.25V + 0.20T + 0.15K + 0.10S)`
- **分级：** A≥85 / B≥70 / C≥60 / D<60
- **联动：** `alarm_conf_final = raw × (0.5 + 0.5 × dq/100)`

### B-15 标定与漂移管理接口

- **产出物：** `CalibrationManagementService` / `CalibrationController`
- **能力：** 标定版本（DRAFT→ACTIVE→EXPIRED→SUPERSEDED）、漂移复核、到期工单、校正预览

### B-16 边缘断网补偿接口

- **产出物：** `POST /api/ingest/backfill`
- **能力：** batchNo / seqNo / originalSampleTime 必填；乱序可接受；重复幂等；冲突 409

### B-17 告警规则引擎一期骨架

- **产出物：** `AlertRuleEngineService` / `AlertController`
- **能力：** 阈值/组合规则、DQ 降权置信度、自动触发与手动回放评估

### B-18 告警去重/抑制/升级服务

- **产出物：** `AlertCaseLifecycleService` / `AlertCaseEntity` / `AlertPolicyEntity`
- **能力：** dedupe_key、抑制窗口、升级策略、自动恢复扫描

### B-19 事件化服务

- **产出物：** `IncidentEventizationService` / `IncidentController`
- **能力：** 告警→事件转化、人工确认、低 DQ 进入人工确认流

### B-20 Outbox 与 Relay

- **产出物：** `OutboxService` / `OutboxRelayService` / `OutboxRelayScheduler` / `OutboxEventEntity`
- **能力：** 事务事件写入、Relay 认领、失败重试、状态 NEW→SENDING→SENT→FAILED→DEAD

### B-21 幂等键与死信处理

- **产出物：** `IdempotentConsumerService` / `IdempotentRecordEntity` / `DeadLetterEntity`
- **能力：** 幂等键 = `incident_id + action_type + version`

### B-22 工单服务

- **产出物：** `WorkOrderService` / `WorkOrderController`
- **能力：** 创建/派单/接单/转派/完成/关闭/回写 + 状态机校验 + 一事件多工单

### B-23 通知服务

- **产出物：** `NotificationService` / `NotificationController` / `NotificationRetryScheduler`
- **能力：** 只消费稳定工单事件（白名单）、多通道模拟发送、重试与死信

### B-24 WebSocket 推送网关

- **产出物：** `WebSocketPushGatewayService` / `WebSocketAuthHandshakeInterceptor` / `WebSocketAuthChannelInterceptor`
- **能力：** STOMP 推送、握手鉴权、消息层鉴权、心跳、ack、last_ack_seq 补发

### B-25 模型网关一期框架

- **产出物：** `ModelGatewayService` / `ModelGatewayController` / `RuleFallbackService`
- **能力：** 模型注册/版本/灰度/回退/规则兜底/模拟推理/审计

### B-26 特征视图与算法脱敏接口

- **产出物：** `FeatureViewService` / `FeatureViewController`
- **能力：** 默认 MASKED 视图（哈希 ID、粗粒度坐标）；DETAIL 需限时授权 + 全量审计

### B-27 统一审计日志服务

- **产出物：** `UnifiedAuditService` / `AuditLogController` / `AuditLogEntity`
- **能力：** 跨域审计、应急旁路专项报表查询

### B-28 Trace 与链路埋点中间件

- **产出物：** `TraceIdFilter`（HTTP）+ `TraceIdContext`（MDC）+ WebSocket 拦截器
- **能力：** HTTP / Outbox / 通知 / WebSocket 统一透传 traceId
